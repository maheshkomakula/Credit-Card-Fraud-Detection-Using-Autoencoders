# Credit Card Fraud Detection Dataset

The dataset used in this project is the **Credit Card Fraud Detection dataset** originally hosted on [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

Due to GitHub's file size limitation (100 MB max per file), the 150.8 MB CSV file (`creditcard.csv`) is excluded from git tracking via `.gitignore`.

### To obtain the dataset:
Run the automatic downloader script:
```bash
python dataset/download_dataset.py
```
Or manually download `creditcard.csv` from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and place it directly into this `dataset/` directory.
